# LiveMap 가치 제안

## 핵심 가치

**"1/1000 비용으로 실시간 검증 국제 뉴스"**

---

## 문제 영역

### 현재 시장 페인 포인트

| 문제 | 피해자 | 문제의 비용 |
|---------|-------------|-----------------|
| 느린 뉴스 감지 | 금융 기관, 미디어 기업 | 기회 손실, 지연된 대응 |
| 검증되지 않은 정보 | 모든 사람 | 허위 정보 확산, 신뢰 저하 |
| 비싼 인텔리전스 도구 | 중소기업, 연구자, 기자 | 기업 도구에 연 $20K-$200K |
| 블랙박스 알고리즘 | 투명성이 필요한 사용자 | 결과를 감사하거나 신뢰할 방법 없음 |

## 우리의 솔루션

### 핵심 차별점

#### 1. 소스 비용 제로

| 경쟁사 | 소스 비용 | 우리 비용 |
|------------|-------------|----------|
| Dataminr | 독점 firehose ($$$) | $0 |
| Bloomberg Terminal | 라이선스 피드 ($$$) | $0 |
| 전통 뉴스룸 | 통신사 (연 $50K+) | $0 |

**방법**: 완전히 무료인 공개 데이터 소스 사용:
- [GDELT Project](https://www.gdeltproject.org/) - 100,000개+ 뉴스 소스
- [USGS](https://earthquake.usgs.gov/) / [NOAA](https://www.noaa.gov/) - 정부 데이터
- Reddit, Bluesky - 소셜 신호

#### 2. 다중 소스 검증

단일 소스 플랫폼과 달리, 우리는 게시 전 **2개 이상의 독립 소스**를 요구합니다.

```
이벤트 감지 → 교차 소스 매칭 → Two-Source 검증 → 게시
       ↓                    ↓                      ↓                    ↓
    모든 소스가           여러 소스에서         2개 이상              신뢰도
    감지 가능           동일 이벤트 찾기      소스로 검증          점수와 함께 게시
```

**결과**: 단일 소스 경쟁사보다 낮은 오탐률.

#### 3. 투명한 신뢰도 점수

모든 기사는 **왜** 우리가 신뢰하는지 정확히 보여줍니다:

| 신뢰 수준 | 소스 | 점수 | 예시 |
|------------------|---------|-------|---------|
| 매우 높음 | USGS/NOAA | 0.99 | 지진 경보 |
| 높음 | 2개+ Tier-1 뉴스 | 0.85+ | Reuters + AP가 동일 이벤트 보도 |
| 게시 가능 | Tier-1 뉴스 | 0.70+ | 단일 GDELT 기사 |
| 신호만 | 소셜 미디어 | 0.45 | Reddit 게시물 (게시 안 함) |

#### 4. AI 기반 비용 효율성

**3단계 검증 파이프라인**:
1. **규칙** (무료): 70% 비이벤트 필터링
2. **Zero-shot ML** (무료): 로컬 모델이 20% 추가 분류
3. **LLM** (유료): 10%의 이벤트만 API 호출 필요

**비용 비교**:
| 접근 방식 | 일일 비용 |
|----------|----------|
| LLM 단독 | $16.13 |
| 규칙 + LLM | $4.80 |
| **규칙 + ML + LLM** | **$1.44** |

## 경쟁 해자

### 기술적 우위

1. **다중 소스 파이프라인**: 14개+ 소스 통합 복제 어려움
2. **검증 알고리즘**: 시간에 걸쳐 조정된 독자적 신뢰도 점수
3. **SOTA 주장 검증**: 2026 연구 기반 (VeriScore, AIC CTU 방법)
4. **비용 구조**: 기사당 거의 제로 한계 비용

### 네트워크 효과

1. 더 많은 사용자 → 더 나은 피드백 → 더 나은 검증
2. 더 많은 소스 통합 → 더 높은 정확도 → 더 많은 신뢰
3. 공개 방법론 → 커뮤니티 기여 → 지속적 개선
