# LiveMap - 투자자 요약

## 경영 요약

LiveMap은 다중 소스 교차 검증을 통해 전통 미디어보다 더 빠르고 정확하게 국제 속보를 전달하는 **AI 기반 실시간 뉴스 검증 플랫폼**입니다.

**미션**: *"누구보다 빠르게, 검증된, 편향 없는 국제 정세 뉴스"*

---

## 문제 정의

### 현재 뉴스 환경의 문제점

| 문제 | 영향 |
|---------|--------|
| **느린 감지** | 전통 미디어는 소셜 신호보다 15-60분 뒤처짐 |
| **검증되지 않은 루머** | 소셜 미디어가 허위 정보를 빠르게 확산 |
| **편집 편향** | 인간 편집자가 정치적/상업적 편향 도입 |
| **비싼 솔루션** | Dataminr 같은 기업 도구는 월 $20,000+ |
| **정보 과잉** | 큐레이션 없이 매일 수백만 개의 뉴스 기사 |

### 시장 페인 포인트

1. **기업**은 실시간 인텔리전스가 필요하지만 프리미엄 가격 지불
2. **일반 대중**은 빠르고 검증된 속보에 접근 부족
3. **연구자**는 투명하고 재현 가능한 뉴스 데이터 필요
4. **미디어 매체**는 대규모 검증에 어려움

---

## 우리의 솔루션

### 다중 소스 교차 검증

LiveMap은 **여러 독립적인 소스**를 결합하여 속보를 자동으로 검증합니다:

```
소셜 신호 (속도)         +     뉴스 소스 (권위)
        ↓                               ↓
   조기 감지                    교차 검증
        ↓                               ↓
        └──────── 검증된 뉴스 ────────┘
```

### 핵심 혁신: 신뢰도 점수

모든 기사에 **투명한 신뢰도 점수** 포함:
- 독립 소스 수
- 소스 신뢰도 티어
- 교차 검증 매칭
- 주장 검증 결과

## 기술 해자

### 1. 다중 소스 아키텍처

**14개+ 통합 소스** 3개 티어에 걸쳐:
- Tier-1: GDELT, USGS, NOAA, EMSC (권위적)
- Tier-2: Currents API, World News API, ACLED (2차)
- Tier-3: Reddit, Bluesky, Telegram, Google Trends (신호)

### 2. GDELT 이상 탐지

GDELT 이상 탐지 API의 독자적 활용:
- `timelinevolraw`: 볼륨 스파이크 감지
- `GKG Themes`: 위기 테마 모니터링
- `Goldstein Score`: 분쟁 강도 측정

### 3. AI 기반 주장 검증

LLM 기반 검증 파이프라인:
1. 기사에서 주장 추출
2. 여러 소스에서 증거 검색
3. 판정 할당 (SUPPORTED/REFUTED/NEI)
4. 신뢰도 점수화

### 4. 3단계 이벤트 검증 (신규)

비용 효율성을 위한 하이브리드 검증 파이프라인:
1. **규칙 기반 필터링** ($0): 정규식 패턴으로 70% 비이벤트 필터링
2. **Zero-shot 분류** ($0): 로컬 ML 모델 (BART-MNLI)로 나머지 이벤트 분류
3. **LLM 검증** ($0.001/이벤트): 불확실한 경계 케이스만 유료 LLM 사용

**결과**: LLM 단독 대비 90% 비용 절감 ($1.44/일 vs $16.13/일)

### 5. 소셜 속도 알고리즘

소셜 미디어 속도 측정을 통한 조기 감지:
- Reddit 업보트 속도
- Bluesky 게시물 전파
- Google Trends 브레이크아웃 감지
- Telegram 채널 확산

## 기술 아키텍처

### 처리 파이프라인

```
15분 주기:
├─ Stage 1: 병렬 감지
│  ├─ GDELT 이상 탐지
│  ├─ 소셜 속도 모니터링
│  └─ 특화 API (USGS, NOAA)
│
├─ Stage 2: 교차 검증
│  ├─ 다중 소스 매칭
│  ├─ 주장 추출 & 검증
│  └─ 신뢰도 점수화
│
└─ Stage 3: 게시
   ├─ 기사 생성 (이중 언어)
   └─ 소스 인용
```

### 핵심 지표

| 지표 | 목표 | 현재 |
|--------|--------|---------|
| 감지 지연 | < 15분 | 개발 중 |
| 오탐률 | < 5% | 개발 중 |
| 소스 커버리지 | 14개+ 소스 | 구현 중 |
| 검증 정확도 | > 90% | 개발 중 |

## 저널리즘 표준

### IFCN 준수

International Fact-Checking Network의 5대 원칙을 모두 준수:

1. **비당파성**: 알고리즘 기반, 편집 편향 없음
2. **소스 투명성**: 모든 기사에 모든 소스 인용
3. **자금 투명성**: 광고 또는 후원 콘텐츠 없음
4. **방법론 투명성**: 공개 문서화
5. **정정 정책**: 오류 발견 시 즉시 정정

### Two-Source Rule

게시 전 2개 이상의 독립 소스를 요구하는 업계 표준 저널리즘 관행.

## 요약

LiveMap은 **소스 비용 제로로 검증된 속보**를 제공합니다:

1. **다중 소스 감지** (14개+ 소스)
2. **AI 기반 검증** (주장 수준)
3. **투명한 신뢰도 점수** (IFCN 준수)
4. **실시간 처리** (15분 주기)

**핵심 차별점**:
- 비용: $0 vs 경쟁사 $20,000+/월
- 속도: 전통 미디어보다 15-60분 빠름
- 정확도: 다중 소스 검증으로 오탐 감소
- 투명성: 공개 방법론 및 소스 인용
