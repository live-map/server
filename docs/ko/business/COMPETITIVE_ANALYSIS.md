# 경쟁 분석

## 시장 개요

Open Source Intelligence (OSINT) 및 실시간 뉴스 인텔리전스 시장은 금융 기관, 미디어 기업, 정부 기관의 더 빠르고 정확한 정보에 대한 수요로 빠르게 성장하고 있습니다.

---

## 경쟁사 현황

### Tier 1: 엔터프라이즈 OSINT 플랫폼

#### Dataminr

**개요**: 공개 데이터에서 이벤트를 감지하는 선도적인 실시간 AI 플랫폼.

| 항목 | 세부 사항 |
|--------|---------|
| 가격 | 연 $20,000 - $200,000+ |
| 타겟 시장 | 엔터프라이즈 (금융, 미디어, 정부) |
| 주요 소스 | Twitter/X firehose, 뉴스 API |
| 강점 | 속도, 규모, 확립된 브랜드 |
| 약점 | 비쌈, 블랙박스, Twitter 의존 |

**LiveMap 대비 비교**:
| 기능 | Dataminr | LiveMap |
|---------|----------|---------|
| 비용 | 연 $200K+ | 연 ~$2,400 |
| 소스 투명성 | 낮음 | 높음 |
| 검증 | 제한적 | 다중 소스 |
| API 접근 | 엔터프라이즈만 | 오픈 |

---

#### Recorded Future

**개요**: 뉴스 모니터링 기능을 갖춘 위협 인텔리전스 플랫폼.

| 항목 | 세부 사항 |
|--------|---------|
| 가격 | 연 $100,000 - $300,000+ |
| 타겟 시장 | 보안팀, 정부 |
| 주요 초점 | 사이버보안 위협 |
| 강점 | 깊은 위협 인텔리전스, 분석가 지원 |
| 약점 | 보안 중심만, 매우 비쌈 |

**LiveMap 대비 비교**:
| 기능 | Recorded Future | LiveMap |
|---------|-----------------|---------|
| 비용 | 연 $200K+ | 연 ~$2,400 |
| 초점 | 보안 위협 | 국제 정세 |
| 검증 | 분석가 주도 | 자동화 다중 소스 |
| 커버리지 | 사이버 + 지정학 | 지정학 중심 |

#### Palantir

**개요**: 뉴스 인텔리전스 기능을 갖춘 데이터 분석 플랫폼.

| 항목 | 세부 사항 |

| 타겟 시장 | 정부, 대기업 |
| 주요 초점 | 데이터 통합 및 분석 |
| 강점 | 강력한 분석, 정부 계약 |
| 약점 | 극도로 비쌈, 복잡한 배포 |

**LiveMap 대비 비교**:
| 기능 | Palantir | LiveMap |
|---------|----------|---------|
| 비용 | 시트당 $173K+ | 연 ~$2,400 |
| 배포 | 복잡한 엔터프라이즈 | 간단한 API |
| 초점 | 전체 데이터 플랫폼 | 뉴스 검증 |
| 접근성 | 엔터프라이즈만 | 누구나 |

## 우리의 경쟁 우위

### 1. 비용 리더십

엔터프라이즈 경쟁사 대비 **99% 비용 절감**:
- Dataminr: $200K → LiveMap: $2.4K = **83배 저렴**
- Bloomberg: $24K → LiveMap: $2.4K = **10배 저렴**

**달성 방법**:
- 무료 데이터 소스 (GDELT, USGS, Reddit)
- 3단계 검증 파이프라인 (91% LLM 비용 절감)
- 비싼 데이터 라이선스 없음

### 2. 투명성

| 경쟁사 | 결정 방법 | 감사 가능? |
|------------|------------------------|------------|
| Dataminr | 독점 AI | 아니오 |
| Bloomberg | 편집 판단 | 부분적 |
| LiveMap | **공개 알고리즘 + 신뢰도 점수** | **예** |

### 3. 검증 품질

| 경쟁사 | 검증 방법 |
|------------|---------------------|
| Dataminr | 정확도보다 속도 |
| NewsAPI | 없음 |
| LiveMap | **Two-Source Rule + 주장 수준 검증** |

### 4. IFCN 준수

[International Fact-Checking Network](https://www.ifcncodeofprinciples.poynter.org/) 원칙을 따릅니다:

1. 비당파성 및 공정성
2. 소스 투명성
3. 자금 투명성
4. 방법론 투명성
5. 공개적이고 정직한 정정

**어떤 경쟁사도 IFCN 표준을 공개적으로 약속하지 않습니다.**

## 진입 장벽

### 경쟁사가 쉽게 복제할 수 없는 이유

1. **다중 소스 통합**: 서로 다른 API, 형식, 속도를 가진 14개+ 소스
2. **검증 파이프라인**: 조정된 임계값, 주장 추출, 신뢰도 점수
3. **비용 구조**: 우리의 무료 소스 접근법은 기존 업체에게 수익화하기 어려움
4. **공개 방법론**: 투명성은 기능이지 버그가 아님
