# 중요도 점수 알고리즘

## 개요

중요도 점수기는 Goldstein Scale과 ACLED 방법론에서 파생된 6가지 차원을 사용하여 뉴스 이벤트를 0.0-1.0 스케일로 평가합니다. 이벤트가 처리 및 게시할 가치가 있는지 여부를 결정합니다.

---

## 점수 구성요소

최종 중요도 점수는 6개 구성요소의 가중 합계입니다:

```
중요도 = (이벤트_유형 × 0.20) +
        (행위자_중요도 × 0.20) +
        (지리적_범위 × 0.15) +
        (사상자_규모 × 0.15) +
        (소스_커버리지 × 0.15) +
        (확대_가능성 × 0.15)
```

---

## 1. 이벤트 유형 점수 (Goldstein Scale)

GDELT Goldstein Scale 기반으로, -10(극단적 갈등)에서 +10(극단적 협력)까지 갈등 강도를 측정합니다.

### 정규화

```python
def goldstein_to_importance(goldstein_score: float) -> float:
    """Goldstein (-10 to +10)을 중요도 (0 to 1)로 변환"""
    return (10 - goldstein_score) / 20
```

| Goldstein 범위 | 중요도 | 예시 이벤트 |
|----------------|--------|------------|
| -10 ~ -8 | 0.90-1.00 | 핵 공격, 대량 학살, 전쟁 선언 |
| -8 ~ -5 | 0.75-0.90 | 공습, 테러 공격, 암살 |
| -5 ~ -2 | 0.60-0.75 | 무력 충돌, 쿠데타, 폭동 |
| -2 ~ 0 | 0.50-0.60 | 시위, 제재, 군사 훈련 |
| 0 ~ +5 | 0.25-0.50 | 휴전, 평화 협상, 조약 |
| +5 ~ +10 | 0.00-0.25 | 동맹, 인도주의적 지원, 협력 |

## 2. 행위자 중요도

이벤트에 언급된 행위자의 중요도를 평가합니다.

| 행위자 카테고리 | 점수 | 예시 |
|----------------|------|------|
| UN 안보리 P5 | 0.80-1.0 | 미국, 러시아, 중국, 프랑스, 영국 |
| G7 국가 | 0.65-0.80 | 독일, 일본, 이탈리아, 캐나다 |
| 지역 강대국 | 0.60-0.85 | 이란, 사우디아라비아, 터키, 이스라엘 |
| 국제 기구 | 0.70-0.90 | NATO, UN, WHO, EU |
| 비국가 행위자 | 0.70-0.85 | ISIS, 알카에다, 하마스 |
| 기타 | 0.30-0.50 | 지역 행위자 |

## 3. 지리적 범위

| 범위 | 점수 | 지표 |
|------|------|------|
| 국제 | 0.80-1.0 | 여러 국가, "international", "global" |
| 지역 | 0.50-0.80 | 인접 국가, 지역 기구 |
| 국가 | 0.30-0.50 | 단일 국가, 수도 |
| 지방 | 0.00-0.30 | 도시, 지방, 지역 |

## 중요도 수준

| 점수 범위 | 수준 | 조치 |
|-----------|------|------|
| 0.70-1.00 | **CRITICAL** | 즉시 처리 |
| 0.50-0.69 | **HIGH** | 표준 처리 |
| 0.30-0.49 | **MEDIUM** | 검토 후 처리 |
| 0.00-0.29 | **LOW** | 필터링 |

### 임계값

0.25(LOW) 미만의 점수를 받은 이벤트는 파이프라인에서 필터링됩니다.

## 멀티소스 부스트

여러 소스에서 감지된 이벤트(클러스터링을 통해)는 중요도 점수 부스트를 받습니다:

```python
def apply_multi_source_boost(score: float, cluster_size: int) -> float:
    boost = min(0.1 * (cluster_size - 1), 0.3)  # 최대 +0.3
    return min(score + boost, 1.0)
```

| 클러스터 크기 | 부스트 | 근거 |
|--------------|--------|------|
| 1 소스 | +0.0 | 부스트 없음 |
| 2 소스 | +0.1 | 상호 검증 |
| 3 소스 | +0.2 | 강한 신호 |
| 4+ 소스 | +0.3 | 속보 스토리 |
