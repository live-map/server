## 개요

이 단계는 품질을 향상시키면서 비용을 극적으로 줄인 ML 기반 인텔리전스 레이어를 도입했습니다. 하이브리드 접근 방식은 지능형 사전 필터링을 통해 91% 비용 절감을 달성하면서 zero-shot 분류와 LLM 검증을 결합했습니다.

---

## 주요 성과

### 1. Zero-Shot 분류 (91% 비용 절감)

**돌파구:** LLM 검증 전에 사전 필터링을 위해 BART-MNLI 사용.

```python
# app/agent/zero_shot_classifier.py
class ZeroShotClassifier:
    def __init__(self):
        self.model = pipeline(
            "zero-shot-classification",
            model="facebook/bart-large-mnli"
        )
```

**비용 분석:**
| 단계 | 이벤트당 비용 | 볼륨 | 총액 |
|------|-------------|------|------|
| 이전: 모든 LLM | $0.004 | 1000/일 | $4.00/일 |
| 이후: Zero-shot 필터 | $0.0001 | 1000/일 | $0.10/일 |
| 이후: 통과된 LLM | $0.004 | 100/일 | $0.40/일 |
| **이후 총액** | - | - | **$0.50/일** |

**절감: 91%** ($4.00 → $0.50/일)

### 2. 게이트 시스템 구현

순차적 품질 게이트 도입:

```
입력 이벤트
    ↓
[Gate 0: 이벤트 검증] ─── Zero-shot: "실제 이벤트인가?"
    ↓ (통과: 점수 > 0.6)
[Gate 1: 체크워디니스] ── Zero-shot: "뉴스 가치가 있는가?"
    ↓ (통과: 점수 > 0.5)
[Gate 2: 구체성] ──────── Zero-shot: "구체적 세부사항이 있는가?"
    ↓ (통과: 점수 > 0.4)
[Gate 3: 증거] ────────── LLM: "증거가 충분한가?"
    ↓ (통과: 증거 발견)
검증된 이벤트
```

### 3. DBSCAN 이벤트 클러스터링

멀티소스 이벤트를 식별하기 위해 관련 기사 그룹화.

### 4. 국제 문제 집중

8개 고영향 카테고리로 범위 축소:

| 카테고리 | 예시 |
|----------|------|
| 무력 충돌 | 전쟁, 군사 작전 |
| 테러리즘 | 테러 공격, 극단주의 폭력 |
| 정치 위기 | 쿠데타, 암살, 불안 |
| 자연재해 | 지진, 쓰나미, 허리케인 |
| 인도주의 | 난민 위기, 기근, 전염병 |
| 외교 | 조약, 제재, 협상 |
| 경제 위기 | 통화 붕괴, 시장 폭락 |
| 핵/WMD | 핵 사고, WMD 확산 |
