# Phase 4: 소스 관리

**기간**: 2026년 1월 23-24일
**Git Phases**: 8, 10 (품질 게이트 & 이벤트 검증)

---

## 개요

이 단계는 소스 품질 관리와 콘텐츠 필터링에 집중했습니다. 시스템은 관련성 있고 최신이며 고품질의 이벤트만 처리되도록 포괄적인 날짜 필터링, 증거 품질 제어, 카테고리 기반 콘텐츠 필터를 구현했습니다.

## 주요 성과

### 1. 최신성 필터링

**문제:** 오래된 기사가 새로운 뉴스로 처리됨.

**해결책:** 다층 날짜 필터링:

```python
# Layer 1: 게시 날짜 필터
def filter_old_articles(events):
    cutoff = datetime.utcnow() - timedelta(hours=24)
    return [e for e in events if e.detected_at > cutoff]

```

### 2. URL 날짜 추출

많은 뉴스 URL에 추출 가능한 게시 날짜 포함:

```python
PATTERNS = [
    r'/(\d{4})/(\d{2})/(\d{2})/',     # /2026/01/23/
    r'/(\d{4})-(\d{2})-(\d{2})/',     # /2026-01-23/
    r'/(\d{8})/',                      # /20260123/
]
```

### 3. 증거 소스 필터링

**차단된 소스:**
| 소스 유형 | 이유 |
|-----------|------|
| Wikipedia | 1차 소스 아님 |
| Archive.org | 역사적 콘텐츠 |
| 웹 아카이브 | 오래된 정보일 수 있음 |

### 4. 관련 소스 (법적 준수)

생성된 기사에 출처 표시 섹션 추가:
- 투명성 향상
- 법적 준수 보장
- 사용자 신뢰 구축

### 5. 카테고리 필터

**스포츠 필터:** 3개 이상의 스포츠 키워드가 있으면 필터링
**지역 범죄 필터:** 지역 범죄만 필터링 (국제 범죄는 허용)

## 필터 파이프라인

```
입력 이벤트 (1000/일)
        ↓
[최신성 필터] ──────────── 거부: 24시간 초과
        ↓ (~800 남음)
[콘텐츠 날짜 필터] ─────── 거부: 과거 연도 참조
        ↓ (~700 남음)
[URL 날짜 필터] ────────── 거부: 오래된 URL 날짜
        ↓ (~650 남음)
[스포츠 필터] ──────────── 거부: 스포츠 콘텐츠
        ↓ (~550 남음)
[지역 범죄 필터] ───────── 거부: 지역 범죄만
        ↓ (~500 남음)
[카테고리 분류] ────────── 8개 카테고리로 분류
        ↓
필터링된 이벤트 (500/일)
```
