## P0: 속보 패스트패스

### 소스 티어 시스템

도메인 기반 신뢰도 티어 구현:

| 티어 | 신뢰도 | 최소 소스 | 예시 |
|------|--------|-----------|------|
| **Tier-1** | 0.95 | 1 | Reuters, AP, AFP, UN, NATO |
| **Tier-2** | 0.85 | 1 (+ 검증) | BBC, NYT, CNN, Guardian |
| **Tier-3** | 0.70 | 2 | 지역 신문 |
| **Tier-4** | 0.50 | 3 | 블로그, 집계 사이트 |

### 속보 감지

5가지 감지 신호 조합:

| 신호 | 부스트 | 예시 |
|------|--------|------|
| 속보 키워드 | +0.4 | "BREAKING:", "URGENT:" |
| 플래시 패턴 | +0.3 | "FLASH:", 정규식 패턴 |
| 긴급 이벤트 | +0.2 | "총기 난사", "침공" |
| Tier-1 소스 | +0.2 | Reuters 독점 |
| 볼륨 스파이크 | +0.3 | 정상의 3배 볼륨 |

### 게이트 스킵 메커니즘

Tier-1/2 소스의 속보는 검증 게이트를 건너뛸 수 있음:

```
속보 감지됨 (confidence >= 0.6)
         │
         ├── 높은 신뢰도 (>= 0.8) + Tier-1/2
         │   └── 스킵: Gate 0, Gate 2, Gate 3
         │
         └── 표준 신뢰도 (0.6-0.79) + Tier-1/2
             └── 스킵: Gate 2, Gate 3

검증 라벨:
├── FLASH (15분 재검증)
├── BREAKING (20분 재검증)
└── DEVELOPING (30분 재검증)
```

## P1: 중요도 점수

### Goldstein Scale 통합

GDELT의 갈등 강도 스케일에서 적응:

| Goldstein | 의미 | 예시 |
|-----------|------|------|
| -10 | 극단적 갈등 | 핵 공격 |
| -8 | 높은 갈등 | 전쟁 선언 |
| -5 | 중간 갈등 | 암살 |
| 0 | 중립 | 군대 배치 |
| +5 | 높은 협력 | 평화 협정 |

### 6차원 점수

| 차원 | 가중치 | 범위 | 설명 |
|------|--------|------|------|
| 이벤트 유형 | 20% | 0-1 | Goldstein Scale 정규화 |
| 행위자 중요도 | 20% | 0-1 | P5, G7, 지역 강대국 |
| 지리적 범위 | 15% | 0-1 | 지역 (0) ~ 국제 (1) |
| 사상자 규모 | 15% | 0-1 | 로그 스케일 |
| 소스 커버리지 | 15% | 0-1 | Tier-1/2 소스 존재 |
| 확대 가능성 | 15% | 0-1 | "전쟁 위협" → 0.95 |

### 새로운 API 소스

| 소스 | 티어 | 커버리지 |
|------|------|----------|
| Currents API | Tier-2 (0.75) | 글로벌 뉴스 집계 |
| WorldNews API | Tier-2 (0.75) | 다국어 지원 |

## 현재 상태

이 단계는 2026년 1월 24일 현재 시스템의 현재 상태를 나타냅니다. 파이프라인은 이제 다음을 갖추고 있습니다:
