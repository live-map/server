# ADR-007: 속보 패스트패스

## 상태
승인됨

## 컨텍스트

표준 검증 파이프라인은 모든 이벤트를 여러 게이트(Gate 0-3)를 통해 처리하며, 이벤트당 30-45초가 소요됩니다. 신뢰도 높은 소스의 속보에 대해서는 이 지연이 허용되지 않습니다:

- 통신사(Reuters, AP, AFP)는 검증된 콘텐츠를 게시
- 독자들은 주요 이벤트에 대한 즉각적인 업데이트 기대
- 경쟁사는 속보를 즉시 게시
- 지연은 관련성과 사용자 신뢰를 감소시킴

## 결정

Tier-1/2 소스에 대한 게이트 스킵과 함께 5가지 감지 신호를 사용하는 속보 패스트패스를 구현합니다.

### 감지 신호

| 신호 | 신뢰도 부스트 | 트리거 |
|------|-------------|--------|
| 속보 키워드 | +0.4 | "breaking", "urgent", "flash", "alert" |
| 플래시 패턴 | +0.3 | `FLASH:`, `URGENT:`, `BREAKING:` 정규식 |
| 긴급 이벤트 | +0.2 | 테러 공격, 침공, 대규모 사상자 |
| Tier-1 소스 | +0.2 | Reuters, AP, AFP 도메인 |
| 볼륨 스파이크 | +0.3 | 정상의 3배 언급 볼륨 |

**속보 임계값:** 결합된 신뢰도 ≥ 0.6

### 게이트 스킵 규칙

| 조건 | 스킵되는 게이트 |
|------|----------------|
| 높은 신뢰도 (≥0.8) + Tier-1/2 | Gate 0, Gate 2, Gate 3 |
| 표준 신뢰도 (0.6-0.79) + Tier-1/2 | Gate 2, Gate 3 |
| 비-Tier-1/2 소스 | 스킵 없음 |

### 보상 조치

1. **라벨 투명성**: 기사에 "DEVELOPING" 또는 "BREAKING" 표시
2. **예약된 재검증**: 간격을 두고 자동 검증
3. **Gate 1 필수**: 체크워디니스 게이트는 절대 스킵 안 됨
4. **소스 티어 요구사항**: Tier-1/2 소스만 자격

## 결과

### 긍정적
- 속보 지연 45초에서 5초로 감소 (-89%)
- 통신사 독점 즉시 게시
- 소스 티어 요구사항으로 정확성 유지
- 개발 중인 스토리 라벨로 사용자 신뢰 향상

### 부정적
- 초기 게시 시 오류 가능성
- "DEVELOPING" 라벨이 인지된 신뢰도 감소시킬 수 있음
- 재검증이 추가 처리 부하 생성
