# ADR-011: 도메인 기반 티어 시스템

## 상태
승인됨

## 컨텍스트

기존 티어 시스템(ADR-003)은 **트리거 소스**(GDELT, USGS, Reddit)를 분류하지만 해당 소스 내의 개별 **도메인**은 분류하지 않습니다. 이로 인해 문제가 발생했습니다:

1. GDELT는 신뢰도가 다양한 수천 개의 출판사에서 집계
2. GDELT를 통한 Reuters 기사는 블로그와 다르게 처리되어야 함
3. Two-Source Rule이 소스 품질을 고려할 수 없음
4. 통신사의 속보가 불필요하게 지연됨

## 결정

기존 트리거 티어 시스템을 보완하는 4티어 도메인 분류 시스템을 구현합니다.

### 도메인 티어 구조

| 티어 | 신뢰도 | 최소 소스 | 단일 소스 | 패스트패스 |
|------|--------|-----------|-----------|-----------|
| **Tier-1** | 0.95 | 1 | 예 | 예 |
| **Tier-2** | 0.85 | 1 (60분 검증) | 예 | 예 |
| **Tier-3** | 0.70 | 2 | 아니오 | 아니오 |
| **Tier-4** | 0.50 | 3 | 아니오 | 아니오 |

### 티어 정의

**Tier-1: 통신사 & 공식 소스**
- 통신사: Reuters, AP, AFP
- 정부: UN, NATO, WHO, 국무부
- 근거: 전문 편집 기준, 원본 보도

**Tier-2: 주요 뉴스 매체**
- 미국: NYT, Washington Post, CNN, NPR
- 영국: BBC, Guardian, Telegraph, FT
- 유럽: DW, France24, Le Monde
- 근거: 확립된 뉴스룸, 팩트체킹 프로세스

**Tier-3: 지역/전문**
- 지역: LA Times, Chicago Tribune, Irish Times
- 전문: Defense News, Nature, Science
- 근거: 신뢰할 수 있지만 범위가 좁음

**Tier-4: 기타**
- 미등록 도메인의 기본값
- 블로그, 집계 사이트, 알려지지 않은 소스
- 근거: 검증되지 않은 편집 기준

### Two-Source Rule 강화

Two-Source Rule은 이제 다음에 의해 충족됩니다:
1. 단일 Tier-1 도메인 소스 (즉시 게시)
2. 단일 Tier-2 도메인 소스 (60분 검증 후)
3. 2개 이상의 다른 도메인 소스 (표준 규칙)

## 결과

### 긍정적
- 통신사 기사 즉시 게시
- 집계 사이트 내 품질 차별화
- 속보 패스트패스 활성화
- 더 정확한 신뢰도 점수
- Two-Source Rule 무결성 유지

### 부정적
- 도메인 목록 유지보수 부담
- 새로운 신뢰할 수 있는 매체 누락 가능
- 티어 할당의 주관성
- 관리할 두 개의 티어 시스템
