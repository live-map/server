## 1. 뉴스 트리거 API 비교

### 1.1 GDELT (추천)

| 항목 | 내용 |
|------|------|
| **가격** | **무료** (제한 없음) |
| **커버리지** | 100,000+ 뉴스 소스, 100+ 언어, 전 세계 |
| **업데이트** | 15분마다 |
| **검색 방식** | 키워드 기반 글로벌 검색 (Boolean 지원) |
| **소셜 미디어** | ❌ 직접 지원 안 함 (뉴스 기사 내 인용만) |

**장점:**
- 완전 무료, 제한 없음
- 뉴스 커버리지 최고
- 215년치 역사 데이터

**단점:**
- 뉴스만 커버 (텔레그램, X 안 됨)
- 실시간이 아님 (15분 딜레이)

**월 비용 (3,000건):** **$0**

```python
# GDELT 사용 예시

    query="protest OR war OR violence",
    start_date="2026-01-12",
```

## 2. 소셜 미디어 API 비교

### 2.1 텔레그램

#### 공식 API (channels.searchPosts)

| 항목 | 내용 |
|------|------|
| **가격** | Telegram Stars (정확한 가격 미공개) |
| **커버리지** | **모든 공개 채널** 글로벌 검색 |
| **검색 방식** | 키워드 기반 |
| **개인 채널** | ❌ 비공개/개인 채널 불가 |

**장점:**
- 공개 채널 전체 검색 가능
- 실시간

**단점:**
- 가격 불명확 (Telegram Stars)
- 비공개 채널 접근 불가

#### Telethon (Python 라이브러리)

| 항목 | 내용 |
|------|------|
| **가격** | **무료** |
| **커버리지** | **가입한 채널만** |
| **검색 방식** | 가입한 채널 내 키워드 검색 |
| **개인 채널** | ⚠️ 가입해야 함 |

**장점:**
- 완전 무료
- 파이썬으로 쉽게 사용

**단점:**
- ⚠️ **글로벌 검색 불가** - 가입한 채널만 검색
- 먼저 채널에 가입해야 함

**현실적 접근:**
```python
# Telethon으로는 "가입한 채널"만 검색 가능
# 하지만 주요 OSINT 채널들을 미리 가입해두면 실용적

OSINT_CHANNELS = [
    "ukrainenowenglish",  # 우크라이나
    "nexta_live",         # 벨라루스
    "IranIntl",           # 이란
    "GeoConfirmed",       # OSINT
    # ... 에이전트가 필요시 추가 가입
]
```

**월 비용:** **$0** (가입한 채널 한정)

## 6. API별 상세 스펙

### GDELT API

```python
# 설치
pip install gdeltdoc

# 사용
from gdeltdoc import GdeltDoc, Filters

gd = GdeltDoc()

# 키워드 검색 (소스 지정 없이 글로벌)
f = Filters(
    keyword="protest OR war OR violence OR conflict",
    start_date="2026-01-12",
    end_date="2026-01-12",
    country=["IR", "UA", "SY"]  # 선택적 국가 필터
)

articles = gd.article_search(f)
# 반환: 제목, URL, 날짜, 소스, 언어 등
```

### Tavily API

```python
# 설치
pip install tavily-python

# 사용
from tavily import TavilyClient

client = TavilyClient(api_key="...")

# 검색
result = client.search(
    query="Iran protest latest news",
    search_depth="advanced",
    max_results=10
)
# 반환: 제목, URL, 본문 요약, 관련성 점수
```

### Telethon (텔레그램)

```python
# 설치
pip install telethon

# 사용
from telethon import TelegramClient
from telethon.tl.functions.messages import SearchRequest

client = TelegramClient('session', api_id, api_hash)

# 가입한 채널에서 검색
async def search_channel(channel, query):
    entity = await client.get_entity(channel)
    result = await client(SearchRequest(
        peer=entity,
        q=query,
        filter=InputMessagesFilterEmpty(),
        min_date=None,
        max_date=None,
        offset_id=0,
        add_offset=0,
        limit=100,
        max_id=0,
        min_id=0,
        hash=0
    ))
    return result.messages
```
